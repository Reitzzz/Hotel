# Agent Note: 备注摘要与完整阅读区

Status: implemented

## Problem

住宿记录按各列最长文本设置最小宽度。列宽总和超过屏幕可容纳的表格宽度时，最右侧备注被裁掉，也没有明确的完整阅读入口。

## Decision

2026-11-23 用户确认调整列宽、增加选中记录的完整备注区，并明确拒绝横向滚动条。此约束适用于本应用住宿记录表；以后调整表格布局仍需遵守，除非用户明确改变偏好。

短字段按内容紧凑分配宽度，名称和备注优先使用剩余空间；空间不足时收缩列宽，保证九列留在表格内。备注左对齐，过长时按实际字体和列宽显示带省略号的摘要。原始备注独立保留，表单、保存和复制始终使用完整文本。

表格下方设置只读、自动换行的完整备注区，随鼠标或方向键选择更新，支持选择复制和复制整条备注。2026-11-23 用户补充显示条件：只有选中具体住宿记录时才显示整个备注区；启动、取消选择和切换年份后清空并隐藏，将空间还给表格。选中没有备注的记录时仍显示备注区，提示“这条记录没有备注。”并禁用复制按钮。此条件替代无选中项时保留占位提示的行为，避免浏览列表时空框占用高度。

阅读区按实际换行数在 2–5 行之间调整高度；超过 5 行时提示用滚轮浏览全文，不添加滚动条。点击表格后焦点留在表格，方便连续用方向键选择记录。

窗口最小宽度使用受控的列宽需求，备注原文长度不再撑大窗口；列宽计算扣除当前 clam 主题两侧各 2 像素的边框。短字段首先按字体测量分配，空间不足时先收缩名称和备注，仍不足才收缩其他列。列宽由程序管理，列分隔线拖动被拦截，避免手动拖宽后重新挤掉右侧内容。

## Alternatives considered

- 横向滚动条：改动小，能够访问被遮挡的列；用户明确不接受，不能作为窄窗口兜底重新加入。
- 仅加宽备注列：能直接显示当前较短的备注；九列共享有限宽度，窗口变窄或出现更长备注时仍会裁切。
- 每行备注直接换行：无需选择记录即可阅读；会增加表格高度并降低多条住宿记录的浏览密度，本次保留单行表格，完整内容集中在选中记录下方。

## Consequences

备注在有限宽度内有明确的摘要和完整阅读入口，原始数据格式保持九列 Markdown。完整阅读区仅在选中记录时占用一部分表格高度；显示或隐藏会改变表格可见行数，选中状态下超过 5 行的备注需要在该区滚动；没有新增可见滚动条。

九列同时存在时，极窄窗口无法保证其他长字段全部可见，选中后仍可通过原有表单查看这些字段。若以后要求多个长备注同时展开、同时完整显示全部列，或用户改变滚动条偏好，需要重新评估布局并更新此决定，不应直接恢复按最长备注撑宽表格的策略。
